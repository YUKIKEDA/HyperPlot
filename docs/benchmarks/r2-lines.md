# R2: 折れ線の計測

行 R2（Issue #46）の計測の記録。設計書 §5.1・§5.3 の折れ線を、要件 §5 の参照機で測った。

## 条件

| 項目 | 値 |
| --- | --- |
| 機械 | 参照機（要件 §5）: Core i5-13400F、GeForce RTX 3060 Ti、Windows 11 |
| 線 | 1,920 列の M4 の出力を模した折れ線（1 列に 4 点、7,680 点）。シード `0x4879706572506C6F` の xorshift64* で、高さ 1,080 の中を歩く。太さ 1.5 |
| 描画先 | 1,920 × 1,080（`B8G8R8A8_UNORM`） |
| 場面 | 1 本と 16 本、不透明（アルファ 255）と半透明（128） |

## CPU: 記録（BenchmarkDotNet）

`RenderListBenchmarks`（`Clear` → `SetClip` → `DrawPolyline` を系列の数だけ）。JIT、論理プロセッサ 2 に固定、3 回の最良。

| 系列 | 時間 | 確保 |
| --- | --- | --- |
| 1 | 26.8 µs（1 点 3.5 ns） | 0 B |
| 16 | 444 µs | 0 B |

- 最初の実装は、外接矩形を線分ごとに `MathF.Min` / `Max` 4 回で求め、1 本 58.6〜62.5 µs、16 本 944〜980 µs だった。点ごとに `Vector2.Min` / `Max` を 1 回ずつにして、上の値になった（同じ回の中で前後を交互に測ってはいない。差は約 2 倍で、各回の標準偏差は 1〜5%）

## GPU と CPU: 描画（スクラッチ、ハードウェア）

`IGpuBackend.Draw` の前後と、折れ線ごとの 3 回の描画の後にタイムスタンプのクエリを置き、4 フレーム後に読んだ（`bench.mdc`）。1,200 フレーム（最初の 30 フレームは捨てる）、場面を交互に 3 回。GPU は測っている間 P0（1,935〜1,965 MHz、`nvidia-smi`）だった。クエリと、描画の回ごとに呼ぶ差し込み口は、測った後に消した。

| 場面 | GPU の中央値 | GPU の p95 | 覆う割合 / 色 / 戻し（中央値） | CPU の `Draw`（中央値 / p95） |
| --- | --- | --- | --- | --- |
| 1 本、不透明 | 28.7〜33.8 µs | 92〜103 µs | 8〜9 / 11〜12 / 10〜12 µs | 5.5〜6.1 / 8〜24 µs |
| 1 本、半透明 | 28.7 µs | 91〜96 µs | 7〜8 / 11 / 10 µs | 5.3〜5.5 / 7〜22 µs |
| 16 本、不透明 | 477〜480 µs | 733〜747 µs | 122 / 186〜187 / 167〜169 µs | 81〜105 / 112〜187 µs |
| 16 本、半透明 | 480 µs | 717〜782 µs | 122〜123 / 187 / 168〜169 µs | 81〜180 / 107〜293 µs |

- 色と戻しの描画が、GPU の時間の約 3/4 を占める。M4 の線は画面の幅いっぱいに広がるので、外接矩形がほぼ全画面になり、2 回とも全画面を塗る。16 本で約 6,600 万画素である
- 不透明と半透明は同じ経路なので、同じ時間である（設計書 §5.3）
- 予想（Issue #46）: GPU は 1 本 0.1〜0.5 ms、16 本 1〜3 ms。どちらも予想より速い。CPU の記録と書き込みは 16 本で 0.3〜1 ms の予想に対し、記録 0.44 ms と `Draw` 0.08〜0.18 ms
- CPU の `Draw` は、各回の前に GPU の完了を待ってから測った（待つ時間は測る範囲の外）。待たずに続けて描くと、16 本の p95 は 3.7 ms になった。GPU が 1 フレームに 480 µs かかる間に CPU が描き続け、ドライバの待ち行列が満ちて `Map` が待つためで、GPU を待つと消えた

### 測り方の誤り（記録）

最初は、各フレームのタイムスタンプを同じフレームの中で待って読んだ。GPU はフレームの間に空になり、`nvidia-smi` の記録で多くの時間を P8（210〜330 MHz）で過ごし、16 本の中央値は 2.8〜3.3 ms と出た。これはクロックの段の値で、描画の費用ではない。上の表は、4 フレーム後に読む形に直した後の値である。
