# W1b2: 層を作る段の計測

行 W1b2（Issue #308）の計測の記録。1e9 点の列のビンを置いてから最初のフレームまでの CPU 時間と、作っている間のフレームの時間を、main（作り終えるまで待つ）と比べた。

## 条件

| 項目 | 値 |
| --- | --- |
| 機械 | 参照機（要件 §5）: Core i5-13400F（16 スレッド）、GeForce RTX 3060 Ti、Windows 11 |
| ビルド | NativeAOT の Release（スクラッチのハーネス、この PR の作業ツリーと main 1c838ee の作業ツリー。測った後にデータと一緒に消した） |
| 描画先 | 1,920 × 1,080、ハードウェア、倍率 1、`Theme.Light`、タイトル「Bins」 |
| データ | `float` のメモリマップのファイル（`samples/Shared/WalkFile.cs` のランダムウォーク、1e9 点で 4 GB、ページキャッシュに載っている）。棒の層が 1 つで、その X の `Stat.Bin()` |
| ワーカー | `PlotWorkerPool.Shared`（15 本）。プロセスの優先度は High |
| 慣らし | 同じタイトルの 1,000 点のビンを 10 フレーム描いてから、1e9 点の仕様を置く |
| 測る範囲 | 最初のフレームは `SetPlot` と `RenderFrame` の 1 回の CPU 時間（`Stopwatch`）。その後は 16.7 ms ごとに `RenderFrame` を呼び、暫定でないフレームが出るまでの各フレーム |
| 回 | main と PR を交互に 3 回ずつ（プロセスを 6 度） |

## 結果

| | 回 | 最初のフレーム | 作り終えた時刻 | 作る間のフレーム（数） | 中央値 / p95 / 最大（ms） |
| --- | --- | --- | --- | --- | --- |
| main | 1 | 3,414 ms | 3.42 s | — | — |
| main | 2 | 3,377 ms | 3.38 s | — | — |
| main | 3 | 3,273 ms | 3.27 s | — | — |
| PR | 1 | 0.06 ms | 3.51 s | 210 | 0.20 / 0.37 / 1.51 |
| PR | 2 | 0.04 ms | 3.26 s | 195 | 0.17 / 0.43 / 2.22 |
| PR | 3 | 0.14 ms | 3.37 s | 202 | 0.16 / 0.37 / 0.90 |

- **待たない**: main の最初のフレームは、ビンを作り終えるまで 3.3〜3.4 s 待つ。PR の最初のフレームは 0.04〜0.14 ms で戻り、作る間に 195〜210 フレームを描く
- **作る時間は同じ**: 作り終えた時刻は PR が 3.26〜3.51 s、main が 3.27〜3.42 s。仕事を列のタスクに移しても、ビンの計算は同じワーカーで回る
- **作る間のフレームが速い**: 作る間は背景とタイトルだけを描く（層がまだない）ので、中央値は 0.2 ms ほど。最大の 0.9〜2.2 ms は、ワーカーと CPU を取り合う分である（Issue #293）
- main の行の「—」: main は最初のフレームで作り終えるので、作る間のフレームはない
