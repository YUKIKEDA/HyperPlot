# R3b2: 重なりと予算の計測

行 R3b2 の計測の記録。設計書 §9 の「重なりと予算（行 R3b2、Issue #472）」の場面を、要件 §5 の参照機で測る。行 R3b2 の実装は 7 本の PR に分かれていて（Issue #472 の 2026-11-21 の決定）、この記録は 1 本目（Issue #577、ブロックと見えるブロック）の分である。後の本の計測は、その本の PR がこの記録に足す。

## 1 本目の結果（Issue #577）

- **道は 1 つのままでよい**: 1e7 点・8 部分の全体表示は、ページを丸ごと描く形でも見えるブロックだけを描く形でも、記録が同じである（1 フレーム 160 回の描画、1e7 点）。GPU 時間の p50 は、丸ごとが 10.63〜11.15 ms、見えるブロックが 10.70〜11.09 ms で、続けて測った 2 回の比（見えるブロック ÷ 丸ごと）は 0.98〜1.01 だった（6 組）
- **64 部分の拡大は要件 P-4 に入る**: CPU 時間と GPU 時間の p95 の和は 11.19〜11.81 ms（3 回）。描画は 1 フレームに平均 202.7 回、最大 384 回で、設計が挙げた最悪の約 9,800 回にはならなかった
- **要件 P-4**: 測った 8 つの場面は、どの回も 16.7 ms 以下である（9.24〜16.04 ms）。行 R3a と R3f の記録で超えていた 8 部分の全体表示（17.5〜17.6 ms）は 11.79〜12.79 ms、6 つの形に分けた層（GPU の p50 だけで 17.3〜18.0 ms）は 12.13〜13.08 ms になった
- **確保**: どの回も、台本の 2 周目の 300 フレームは 0 B
- 値は、ほかのプロセスが 0.7〜13.0 コアを使っている機械でのものである（回ごとの値は表にある）
