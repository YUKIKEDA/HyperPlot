## 読み方

- **要件 P-6**: 固定なし（アプリと同じ置き方）では、マウスだけのフレームの p95 は、CPU が 0.72 ms 以下、GPU が 1.03 ms 以下で、1 本でも 4 本でも 2 ms を下回った
- **main との比べ**: この場面の全部を描き直すフレームは、ビューが変わらないので、計画は M4 も記録もやり直さず、記録した並びを描き直すだけである（§4.8 の差分）。それでも、マウスだけのフレームは写し 1 回とホバーの並びだけを描くので、1 本の GPU 時間は 0.24 ms から 0.05 ms に、CPU 時間の p50 は 0.24〜0.46 ms から 0.07〜0.10 ms になった。ズームの途中のように記録をやり直すフレームとの差は、これより大きい
- **固定ありの 4 本の裾**: 固定すると、GPU のドライバのスレッドも同じコアに載る（`bench.mdc`）。マウスだけのフレームの p95 は、3 回のうち 2 回で 2.4〜2.7 ms になり、main の全部を描き直すフレームも同じ条件で p95 2.2〜3.7 ms だった。下の「2 周目」の計測で、同じ固定ありの 4 本の 1 周目（同じ台本、新しい文字）が 2 回とも p95 0.82 ms と 0.75 ms だったので、この裾は回ごとに出たり出なかったりする、ドライバとの取り合いである（コードの道は同じ）
- **固定なしの 4 本の 1 回目の GPU**（p95 1.032 ms、時間の届いたフレーム 88）: 2 回目と 3 回目は 0.107 ms だった。PR #352 のレビューの後に同じ場面を 5 回測り直すと、p95 は 0.106・0.112・0.107・0.107・0.108 ms（時間の届いたフレーム 287〜296）で、外れは出なかった。時間の届いたフレームが少ないのは、GPU が遅くてクエリの組が空かなかったためである（設計 §5.2）。1 回目は、GPU のクロックの段が低いままの間に測った回と見る（GPU 時間はクロックの段で動く、`bench.mdc`）。CPU 時間（p95 0.718 ms）は要件の内である
- **この PR の全部を描き直すフレームと main**: 固定なしの 1 本で、この PR の p50 が main より 0.12 ms 遅い回が 3 回あった。足した 4 回の交互の計測（下）では、1 回目はこの PR が遅く（0.363 と 0.234）、2〜4 回目は速かった（0.186・0.246・0.214 と 0.342・0.313・0.322）。差の向きが回で変わり、どちらのビルドも p50 が 0.19〜0.25 と 0.31〜0.46 の 2 つの群に分かれるので、プロセスが P コアと E コアのどちらに載ったかの違いで、ビルドの差ではない。固定ありの 1 本も、main 0.64〜0.74、この PR 0.56〜0.71 で重なる

### 足した計測

- **交互の 4 回**（固定なし、1 本、`--hover-whole`、p50 / p95）: main 0.234 / 0.400、0.342 / 0.434、0.313 / 0.358、0.322 / 0.373。この PR 0.363 / 0.663、0.186 / 0.339、0.246 / 0.638、0.214 / 0.469
- **確保**: マウスだけのフレームは、300 フレームで 1 本 370,264 B、4 本 779,600 B を確保した（固定ありは 384,704 B と 794,040 B）。台本を 3 周（990 フレーム）にすると、同じ位置を回る最後の 300 フレームは 1 本も 4 本も 0 B だった。確保は、新しいツールチップの文字が整形のキャッシュ（行 I1c、8,192 項目）に最初の項目を作る分で、項目は文字ごとに 1 度だけ作る。`HitMode.X` のヒットは画素の列ごとに決まるので、1 つのビューの文字の数は、パネルの幅の画素の数（約 1,840）を超えない
- **2 周目**（4 本、`--hover-frames 960`、CPU の p50 / p95）: 1 周目（30〜329 フレーム、文字が新しい）と 3 周目（690〜989 フレーム、文字はキャッシュにある）
  - 固定あり 1 回目: 0.468 / 0.818 と 0.423 / 0.523
  - 固定なし 1 回目: 0.168 / 0.279 と 0.106 / 0.199
  - 固定あり 2 回目: 0.471 / 0.754 と 0.427 / 0.543
  - 固定なし 2 回目: 0.131 / 0.214 と 0.110 / 0.136
  - 新しい文字の整形は、p95 で 0.1〜0.3 ms を足す
