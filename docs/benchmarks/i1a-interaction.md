# I1a: 対話のフレームの計測

行 I1a（Issue #274）の計測の記録。1e9 点の系列を `PlotEngine` に置き、入力の台本（ホイールの拡大と、ドラッグのパン）を流したときの 1 フレームの CPU と GPU の時間、確保、入力 1 つの処理の時間を、要件 P-1（1 フレームの p95 が 8 ms 以下）と照らした（設計 §9 の「対話（行 I1a）」）。

## 条件

| 項目 | 値 |
| --- | --- |
| 機械 | 参照機（要件 §5）: Core i5-13400F、GeForce RTX 3060 Ti、Windows 11 |
| ビルド | NativeAOT の Release（スクラッチのハーネス、この PR の作業ツリー。測った後にデータと一緒に消した） |
| 描画先 | 1,920 × 1,080、ハードウェア、倍率 1、`Theme.Light`（軸のタイトルとタイトルあり） |
| ワーカー | `PlotWorkerPool.Shared`。プロセスの優先度は High |
| データ | y は `float` のメモリマップのファイル（`samples/Shared/WalkFile.cs` のランダムウォーク、1e9 点で 4 GB、ページキャッシュに載っている）、x は `UniformColumn`（0 から 1 刻み） |
| 時刻 | 手で進める `TimeProvider`。各イベントの前に 16.7 ms 進め、イベント 1 つに 1 フレームを描く |
| 台本 | パネルの真ん中でホイールを 60 目盛り（1 目盛り 1.2 倍、ズームのアニメーション 150 ms）、続けて左ボタンを押し、300 回動かし（左へ 2 画素ずつ、上下に ±20 画素）、離す。362 フレーム |
| 慣らし | 整形のキャッシュを 8,192 個の別の文字列で満たし、台本を 1 度流してから全体表示に戻し、2 度目を測る（1 度目の確保は 47 KB: ズームで出る新しいラベルの整形のキャッシュの項目、境界の配列、履歴の容量） |
| 測る範囲 | CPU は `RenderFrame` の 1 回、入力は `OnWheel`・`OnPointer` の 1 回（フレームとは別）、GPU はフレームのタイムスタンプのクエリ、確保は各イベントとフレームの `GC.GetAllocatedBytesForCurrentThread()` の差の和 |
| 回 | 3 回（プロセスを 3 度） |

## 結果

フレームと入力は中央値 / p95 / 最大。

| 回 | フレームの CPU（ms） | フレームの GPU（ms） | 入力（µs） | 確保（362 フレーム） |
| --- | --- | --- | --- | --- |
| 1 | 0.688 / 1.000 / 6.594 | 0.181 / 0.229 / 0.237 | 1.7 / 4.2 / 13.3 | 0 B |
| 2 | 0.697 / 0.946 / 5.624 | 0.181 / 0.227 / 0.236 | 1.4 / 3.2 / 5.4 | 56 B |
| 3 | 0.795 / 1.030 / 5.918 | 0.182 / 0.230 / 0.238 | 2.1 / 4.3 / 16.2 | 0 B |

- **P-1 との比べ**: フレームの CPU の p95 は 1.03 ms 以下、GPU の p95 は 0.23 ms で、どちらも 8 ms を大きく下回る。拡大の後の表示は 1e9 点の約 17,700 点の幅（1.2^60 ≈ 5.6 万倍）で、M4 の取り出しは画素列の数で抑えられる
- **最大**: CPU の最大（5.6〜6.6 ms）は 362 フレームのうち 1 つで、p95 の約 6 倍。このハーネスはフレームごとの値を残していないので、どのフレームかは分からない（8 ms は下回る）
- **入力**: 1 つの処理は p95 で 4.3 µs 以下。ツールを選び、ビューの操作の API で提案を作り、原点を付け直し、履歴に積み、フレームを要求するまで
- **確保**: 2 度目の台本で 0 B。2 回目の 56 B は、NativeAOT が初めて `Lock` を待つときの初期化の確保で（不変条件 3 の除外）、プロセスに 1 度だけ出る
- **最初のフレーム**: 1 回目は 416 ms、2・3 回目は約 400 ms（ピラミッドの構築を待つ、§4.8 の待ち方）
