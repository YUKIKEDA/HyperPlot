## 要件 P-3: 1e9 点の拡大の台本

P-3 で見るのは、密度で描いたフレームの CPU 時間と GPU 時間の和の p95 である。

【再計測で置き換え】下の表は `Draw = Auto` の計測である。一様な分布は、拡大の途中で画面内の点が 1e7 の 0.8 倍を下回り、600 フレームのうち 500 フレームを生の点で描いた。この表の一様な分布の行は生の点のフレーム（行 R3b2 で扱う）を含むので、P-3 の判定には使えない。再計測では `Draw = Density` の 3 回で、密度のフレームだけの p95 を書く（場面は、フレームの種類ごとの p50・p95・p99・最大と、1 フレームの和の p95 を出す）。

| 分布（`Auto`） | 密度 / 生の点のフレーム | CPU 時間 p50 / p95 / p99 / 最大 | GPU 時間 p50 / p95 / p99 / 最大 |

| 一様（1 回目） | 100 / 500 | 1.32 / 6.23 / 7.18 / 11.82 ms | 0.71 / 7.87 / 24.56 / 33.95 ms |

| 一様（3 回目） | 100 / 500 | 1.32 / 6.23 / 7.12 / 10.40 ms | 0.60 / 8.59 / 24.42 / 36.10 ms |
| 塊（1 回目） | 600 / 0 | 0.47 / 0.75 / 0.87 / 1.20 ms | 1.47 / 2.61 / 3.38 / 6.75 ms |
| 塊（2 回目） | 600 / 0 | 0.74 / 1.08 / 1.67 / 2.47 ms | 1.59 / 3.24 / 3.97 / 8.88 ms |
| 塊（3 回目） | 600 / 0 | 0.61 / 0.90 / 1.32 / 2.02 ms | 1.61 / 3.15 / 3.87 / 4.71 ms |

- 塊の分布は 600 フレームとも密度で描いた。CPU 時間と GPU 時間の p95 の和は 3.4〜4.3 ms で、16 ms に収まる
- 一様な分布の GPU 時間の p99（24.4〜25.1 ms）と最大（34.0〜36.1 ms）は、生の点のフレームである。【要確認】どのフレームか。1e8 点の `switch` の場面では、密度に戻る前の、画面内に 1e7 点近くの点がある生の点のフレームが 15〜40 ms だった（下の「切り替え」）
- GPU 時間の標本は 600 フレームのうち 588〜592 フレームだった
- 【再計測で置き換え】P-3 の判定: `Draw = Density` の 3 回ずつの、密度のフレームの CPU 時間と GPU 時間の和の p95

## 要件 P-15: 粗い密度と、密度タイルで描かれるまで

仕様を渡して（`SetPlan`）から、16.7 ms ごとに描いたフレームで測る。「粗い密度」は、画像の命令を記録した最初のフレームの終わりで、そのとき索引は粗いスナップショットだけを持つ。「暫定でなくなる」は、確定のスナップショットに密度タイルが付き、全体表示の面が全部 GPU に載ったフレームである。

| 分布 | 回 | ファイル | 粗い密度 | 暫定でなくなるまで |
| --- | --- | --- | --- | --- |
| 一様 | `first` | 書いたばかり（2.9 秒で書いた） | 7.00 秒 | 90.05 秒 |
| 一様 | `zoom` 1〜3 回目 | 前の回のまま | 3.82、8.25、8.69 秒 | 57.79、86.17、83.52 秒 |
| 塊 | `first` | 書いたばかり（7.7 秒で書いた） | 7.45 秒 | 181.18 秒 |
| 塊 | `zoom` 1〜3 回目 | 前の回のまま | 3.15、9.91、6.45 秒 | 158.17、200.16、172.23 秒 |

- 粗い密度は 8 回とも 10 秒以内（3.15〜9.91 秒）で、P-15 の値に収まる。ただし最大の 9.91 秒は値に近い。【再計測で置き換え】3 回の `first` と、そのときの機械の状態
- 暫定でなくなるまでの時間は、確定の公開まで、その後に密度タイルが付くまで、全体表示の面を GPU に送るまで、の 3 つを足した時間である。P-15 の値は前の 2 つに別々にある（確定の公開まで一様 75 秒・塊 180 秒、密度タイルまで 10 秒）。先行の場面は 3 つを分けて出さないので、P-15 と比べられない。2 つの値の和（一様 85 秒、塊 190 秒）を超えた回は、一様の `first`（90.05 秒）と `zoom` の 2 回目（86.17 秒）、塊の `zoom` の 2 回目（200.16 秒）の 3 回だった。【再計測で置き換え】場面は、どの部分の索引も粗いスナップショット・確定のスナップショット・密度タイルに届いたフレームの時刻を出す。確定の公開までを 75 秒・180 秒と、密度タイルが付くまでを 10 秒と比べる
- 【再計測で足す】ページキャッシュに載っていないファイル（`first`）と載っているファイル（`zoom`）の差

## 切り替え: 1e8 点

`switch` の場面（`Auto`、1e8 点）。しきい値は既定の 1e7 点で、生の点へは 0.8 倍を下回ったフレームに切り替わる。

### 一様な分布

暖機の後の 600 フレームのうち、密度が 52、生の点が 548 フレームだった。入れ替わりは 5 回で、1 回は暖機の中（14 フレーム目）、残りの 4 回は 1 周に 2 回（拡大で密度から生の点へ、戻りで生の点から密度へ）である。行ったり来たりはしていない。

| 入れ替わり | 画面の幅（範囲に対して） | 前の 10 フレーム CPU / GPU | 後の 10 フレーム CPU / GPU |
| --- | --- | --- | --- |
| 密度 → 生の点（314、614 フレーム目） | 0.260 | 0.63〜1.00 / 0.20〜0.27 ms | 最初の 2 フレームが 10.1〜11.7 ms、その後 0.74〜0.98 / 3.8〜12.0 ms |
| 生の点 → 密度（288、588 フレーム目） | 0.315 | 0.67〜11.1 / 7.5〜40.4 ms | 0.64〜1.77 / 0.19〜12.2 ms |

- 生の点に切り替わった最初の 2 フレームは、CPU 時間が 10〜12 ms になる。【要確認】どの段の時間か。段に分けて測ってから書く
- 生の点から密度に戻る前の生の点のフレームは、GPU 時間が 15〜40 ms だった。画面の幅が範囲の 0.3 ほどで、画面内に 1e7 点近くの生の点がある。行 R3a の全体表示（1e7 点で 8.5〜13.9 ms）より長い。【要確認】このフレームの点の数と、行 R3a との差の理由。行 R3b2 で扱う生の点の重さとして送るかを決める
- 入れ替わりの幅の比は 0.315 / 0.260 = 1.21 で、面積では 1.47 倍である。一様な分布では画面内の点の数は面積に比例するので、しきい値の比（点の数で 1.25 倍）より広い。【要確認】差の 1.47 / 1.25 = 1.18 倍が、フレームの刻み（1 フレームの幅の変わり方）と上限の数え方（`Inside + Touching`）のどちらからか。場面で入れ替わりのフレームの上限を出して確かめる

### 塊の分布

600 フレームとも密度で描き、入れ替わりはなかった。CPU 時間は p50 / p95 / p99 / 最大で 0.63 / 0.84 / 1.03 / 1.65 ms、GPU 時間は 1.57 / 4.81 / 7.72 / 10.91 ms。

- 【要確認】台本のいちばん深い画面でも、画面内の点の上限が 0.8e7 を下回らなかった理由。台本の中心は一様な正方形の中心で、塊の中心とは限らない。再計測では、塊の分布で切り替えを見る台本（塊の中心へ拡大する）を足すか、上限を出して説明する

## 判定
