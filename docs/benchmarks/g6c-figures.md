# G6c: 複数のプロットの図の計測

行 G6c（Issue #258）の計測の記録。2 × 2 の図の 4 つのプロットに同じ 1e9 点の系列を描き、同じ系列の 1 枚の図と比べ、作る時間と 1 フレームの CPU と GPU の時間と確保を、要件 P-1（1 フレームの p95 が 8 ms 以下）と照らした（設計 §4.6）。要件 §5 の参照機で測った。

## 条件

| 項目 | 値 |
| --- | --- |
| 機械 | 参照機（要件 §5）: Core i5-13400F、GeForce RTX 3060 Ti、Windows 11 |
| ビルド | NativeAOT の Release（スクラッチのハーネス、この PR の作業ツリー。測った後にデータと一緒に消した） |
| 描画先 | 1,920 × 1,080、ハードウェア、倍率 1、`Theme.Light`（どのプロットも軸・グリッド・軸のタイトル・タイトルあり） |
| ワーカー | `PlotWorkerPool.Shared`（15 スレッド）。プロセスの優先度は High |
| データ | y は `float` のメモリマップのファイル（`samples/Shared/WalkFile.cs` のランダムウォーク、1e9 点で 4 GB、ページキャッシュに載っている）、x は `UniformColumn`（0 から 1 刻み） |
| 場面 | **1 枚の図**: line 1 本の `PlotSpec` を `Render(PlotSpec)`。**図**: 同じ line のプロット 4 つ（タイトルだけ違う）を `Figure.Grid(2, 2, …)` で `Render(FigureSpec)`。4 つのプロットは同じ y の列を読み、ピラミッドは 1 つを共有する |
| 作る時間 | 最初の `Render` の 1 回（ピラミッド、学習、配置、取り出し、描画） |
| 測る範囲 | 2 秒描いて温めた後の 300 フレーム。y の domain を毎フレーム変える（前もって作った 7 つの仕様か図を順に。図はプロットごと別々に作り、ノードはフレームごとに新しい）。x は全体を表示する。CPU は `HeadlessRenderer.Render` の 1 回、GPU はフレームのタイムスタンプのクエリ、確保は `Render` の前後の `GC.GetAllocatedBytesForCurrentThread()` の差の和 |
| 回 | 場面の順に 1 回ずつを 3 回 |

## 結果

作る時間は ms、フレームは中央値 / p95（µs）。各欄は 1 回目、2 回目、3 回目。

| 場面 | 作る時間 | フレームの CPU | フレームの GPU | 確保（300 フレーム） |
| --- | --- | --- | --- | --- |
| 1 枚の図 | 141、138、136 | 5,036 / 7,436、3,547 / 5,128、3,991 / 5,818 | 795 / 1,078、684 / 786、742 / 805 | 0 B、0 B、0 B |
| 2 × 2 の図 | 135、139、139 | 3,106 / 3,654、3,104 / 3,572、3,581 / 4,512 | 423 / 975、906 / 985、1,041 / 1,159 | 0 B、0 B、0 B |

- **作る時間**: 図は 1 枚の図と同じ。4 つのプロットが同じ列を読み、ピラミッドは図の中で 1 つだけ作る（§5.5.3。プロットごとに作れば 4 倍の仕事と、約 4 % × 4 のメモリになる）。`FigureTests.Pyramids_AreSharedAndExtractedOnce` が 1 つであることを確かめる
- **フレームの CPU**: 図は 1 枚の図より短い。1 系列の取り出しは 1 つのワーカーの 1 つの仕事で（行 G6a の記録）、1 枚の図は 1 系列を約 1,840 の画素列で引く。図は 4 つの系列をそれぞれ約 900 列で引き、4 つの仕事が 1 回の `ExtractTogether` で並んで走るので、最も長い仕事が半分ほどになる。全体の仕事の量（約 3,600 列）は図の方が多いが、待つのは最も長い 1 つ
- **フレームの GPU**: 図は 1 枚の図と同じ桁（4 本の線の頂点は合わせて 1 本の約 2 倍）で、どの回も 1.2 ms を下回る
- **P-1 との比べ**: 図はどの回も p95 が 8 ms を下回る（4.5 ms 以下）。1 枚の図の p95 は 5.1〜7.4 ms で、1 系列を 1 つの仕事で引く全体の表示の取り出しが p95 を決める（行 G6a・G6b の記録と同じ形）
- **確保**: どちらも 0 B。図の仕様と各プロットのノードをフレームごとに新しくしても、図の計画は同じ値の図とセルで何もせず、プロットごとの計画は今の差分のとおり
